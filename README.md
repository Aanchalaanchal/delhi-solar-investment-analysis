# Delhi Solar Investment Analysis

A reproducible techno-economic analysis of rooftop solar PV for a multi-family home in New Delhi.

## Scope

Model electricity generation, household demand, tariffs, and 25-year project cash flows. Compare feasible PV capacities using NPV, IRR, and payback. All unverified inputs must be explicitly labeled illustrative.

## Development roadmap

1. Source and validate Delhi weather, tariffs, and subsidy rules.
2. Build hourly PV and demand models.
3. Implement bill savings and financial optimization.
4. Add a Streamlit dashboard and automated tests.
5. Publish a short investment research report.

**Status:** Repository initialized; financial estimates and investment recommendations are not yet validated.
